# Partner API Quickstart (tutorial)

A step-by-step example showing how a travel partner could call a hotel
availability API, using `api.sandsmacao.com` as the sample base URL.
All values in this repository are placeholders; replace them with your own.

1. Copy `config/example.env` to `.env`.
2. Fill in your own credentials.
3. Run `python examples/availability.py`.
